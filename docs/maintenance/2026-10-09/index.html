Fixed

Project actions open reliably

The menu composition behind the reported “All projects” crash is repaired. Opening project actions now displays the menu without the Base UI error.

Fixed

Diagrams and images stay readable

Diagram labels, including Chinese text, survive safe rendering. Relative paths, absolute paths, and local file URLs load images within the project. Paths outside it and oversized files are rejected.

New Pi integration

Stopped means stopped

Cancellation comes from Pi's final result, including stops made elsewhere. Partial answers remain visible, the status says “Stopped,” and a canceled run sends no success notification.

Accessibility

Actions have their own keyboard targets

Opening a chat and marking it finished are separate buttons. Timestamp contrast, the message input's accessibility attributes, and the conversation heading are corrected.

Quality

Less unnecessary machinery

Removed an unbounded file-icon cache, a redundant loading boundary import, and platform detection that led every download to the same place. Render-time reference mutations were replaced with React's current effect mechanism.

Polish

Appearance reaches the native controls

Light and dark appearance now also guide browser-native controls. Settings preserves the underlying conversation, and the composer remains within the sampled phone layout.

Updated extensions

Current models and honest job outcomes

The optional Fast tier recognizes current supported OpenAI models and providers. The separately installed subagent package records canceled work as canceled.

Connection reliability

Richer results and clean shutdown

The optional MCP package preserves structured results, output descriptions, and error information. A connection stalled during startup can be canceled when Pi shuts down.

Compatibility notes worth knowing

The subscription-usage extension still supports legacy OpenAI Codex sign-in only. Newer OpenAI sign-in tokens are not sent to the old usage endpoint. Graphical extensions remain experimental. The migration does not edit your credentials or existing Pi configuration.

The isolated host check used temporary settings, no credentials, and no model prompt. It confirmed the built-in MCP command, RPC responses, terminal widget rendering, and re-sending a widget after reconnect.
